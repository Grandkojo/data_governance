# QuickLoan Mobile: Ethical Data Review

This repository contains the independent data governance review for QuickLoan Mobile, a fintech startup.

## Project Deliverables

- **[CONSOLIDATED_REPORT.md](CONSOLIDATED_REPORT.md)**: The full ethical review report, including:
  - Governance Review Card (Data Quality, Legal, and Bias risks).
  - Proposed Ethical Reporting Metric (Demographic Parity Ratio).
  - Corrected Data Flow Diagram with annotations.
  - Summary of the Review Process.

## Key Compliance
- Aligned with **Ghana's Data Protection Act (Act 843)**.
- Implements principles of **Data Minimization**, **Consent Management**, and **Algorithmic Fairness**.
